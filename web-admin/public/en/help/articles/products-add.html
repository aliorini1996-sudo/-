How do I add a new item in Field Sales and set its price and unit?

Last updated: 25 November 2026

Open "Products", click "Add item", enter the code, name, unit of measure and base price, then click "Add item".

An item is what your rep sells on the invoice. Its card holds the item code, name, unit of measure and base price.

In this tutorial you open the Products page, add a new item, set its unit and price, and save it.

Video walkthrough

Steps

  1. In the sidebar, click "Products" to open the "Product management" page
  2. Click the "Add item" button at the top of the page to open the "Add new item" window
  3. Enter the "Item code" and "Item name", plus the barcode if there is one
  4. Set the "Main unit", such as carton or piece, then enter the "Main unit price"
  5. Click "Add item" at the bottom of the window to save it and see it in the table

Illustrated guide

Notes and limits

  • Four fields are required and marked with *: "Item code", "Item name", "Main unit" and "Main unit price". The word "Required" appears under the code or the name if you leave it empty.
  • "Main unit" is a free text field that you type yourself (Carton / Piece / Kilo). "Main unit price" is a number that cannot be below zero and accepts decimals.
  • Optional fields in the same window: "Item image", which the rep sees when selling, "Barcode", "Category" and "Status" (Active / Inactive).
  • To edit an item later, click the "Edit" icon in its row. The save button then changes to "Save changes".
  • If the system rejects the save (for example, a duplicate code), a message shows the reason. On success you see "Added".
